# Issue Log

Use this folder for cross-run issues that remain relevant after a single run
closes. Run-local issues belong in `harness/runs/<run>/03_issue_log.md`.

## Naming

```text
YYYY-MM-DD_short_issue_title.md
```

## Severity

- Critical: blocks field operation, data integrity, security, or deployment.
- High: breaks a core MVP workflow or permission rule.
- Medium: important defect with a workaround.
- Low: cleanup, docs, or minor UX issue.
