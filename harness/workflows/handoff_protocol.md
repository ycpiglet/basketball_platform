# Handoff Protocol

Every handoff should be short, current, and actionable.

## Handoff Block

```text
Role handing off:
Role receiving:
Current objective:
Requirement domain:
Phase:
Changed files:
Commands run:
Passing checks:
Known issues:
Next action:
Do not change:
```

## Rules

- Link to the run folder instead of restating everything.
- State uncertainty directly.
- Keep product scope questions separate from implementation issues.
- Do not mark work complete when tests were skipped unless the reason is
  recorded.
- Do not hide failed commands; summarize the failure and next debug step.
