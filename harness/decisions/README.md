# Decisions

Use this folder for architecture or process decisions that should survive beyond
one run.

## Naming

```text
YYYY-MM-DD_short_decision_title.md
```

## When To Add A Decision

- A choice affects multiple future tasks.
- A tradeoff is not obvious from code alone.
- The decision constrains Phase 1 vs Phase 2 scope.
- A permission, data ownership, logging, or deployment rule is clarified.
