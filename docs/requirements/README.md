# Requirements Documents

This folder contains dated, derived requirements and planning documents. The
root files remain the source of truth:

1. `requirements_en.md`
2. `requirements_ko.md`
3. `README.md`
4. `AGENTS.md`

## Preservation Rule

Do not delete, overwrite, or silently narrow an existing requirements document
when creating a new one.

When a new requirements document is created:

- Keep the original source document in place.
- Add a dated summary under `docs/requirements/archive/` when the new document
  depends on or narrows prior scope.
- State the relationship between the old document and the new one.
- Record the new document in `summary/status.md`.
- Link the related harness run from `summary/status.md`.
